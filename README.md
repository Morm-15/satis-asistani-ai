# 🛍️ AI Sales Assistant (Satis Asistani AI)

An intelligent mobile application that helps sellers automate product appraisal using Google Gemini AI. The app analyzes product images to generate detailed descriptions, estimated prices, and selling tips instantly.

## 🚀 Features

* **📸 Instant Analysis:** Capture product photos directly from the mobile app.
* **🧠 AI-Powered:** Utilizes **Google Gemini 1.5 Flash** for accurate image recognition.
* **📊 Smart Data:** Automatically generates:
    * Product Name & Description.
    * Estimated Price Range (Min/Max).
    * Strategic Selling Tips.
* **⚡ Fast & Local:** Optimized for local development with high-speed response.

---

## 🛠️ Tech Stack

* **Mobile App:** React Native, Expo, TypeScript.
* **Backend API:** Node.js, Express, Multer.
* **Artificial Intelligence:** Google Generative AI SDK (Gemini).
* **Language:** TypeScript (Full Stack).
